# TrayMenu.qml – Smooth Entrance + Height Animation

## Goal

Add smooth entrance animation (fade + slide-up) and height transition to `TrayMenu.qml`. Currently menu appears instantly, height jumps from 0 → content height.

## Changes to `modules/popups/TrayMenu.qml`

### 1. Add entrance animation (fade + slide)

```qml
Item {
    id: root

    // ...existing props...

    opacity: 0
    Behavior on opacity {
        NumberAnimation { duration: 150; easing.type: Easing.OutCubic }
    }

    transform: Translate {
        id: entranceSlide
        y: 20
        Behavior on y {
            NumberAnimation { duration: 150; easing.type: Easing.OutCubic }
        }
    }

    Component.onCompleted: {
        opacity = 1;
        entranceSlide.y = 0;
    }
```

### 2. Add smooth height transition

Add after frozenHeight property or near implicitHeight:

```qml
    Behavior on implicitHeight {
        NumberAnimation { duration: 200; easing.type: Easing.OutCubic }
    }
```

Smooth out frozenHeight jump when page content loads.

### 3. Inheriting `transform` from root Item

Verify existing child items don't break from root-level `transform`. Background Rectangle already uses `anchors.fill: parent`, StackView uses `anchors.fill: parent` – both fine with parent Translate.

### 4. StackView transitions – smoother curve + longer duration

Replace all four StackView transitions (pushEnter, pushExit, popEnter, popExit):
- Duration: 200ms → 260ms
- Easing: `Easing.OutCubic` → `Easing.InOutCubic` (symmetric accel/decel, feels more organic)

```qml
pushEnter: Transition {
    NumberAnimation { property: "x"; from: root.menuWidth; to: 0; duration: 260; easing.type: Easing.InOutCubic }
}
pushExit: Transition {
    NumberAnimation { property: "x"; from: 0; to: -root.menuWidth / 3; duration: 260; easing.type: Easing.InOutCubic }
}
popEnter: Transition {
    NumberAnimation { property: "x"; from: -root.menuWidth / 3; to: 0; duration: 260; easing.type: Easing.InOutCubic }
}
popExit: Transition {
    NumberAnimation { property: "x"; from: 0; to: root.menuWidth; duration: 260; easing.type: Easing.InOutCubic }
}
```

### 5. Fix shadowing – pushExit moves old view fully off-screen

**Problem**: `pushExit` moves old view to `-menuWidth/3` = -73px. StackView at `x:0` width 220 clips to `[0, 220]`. Old view visible range: `[0, 147]` — 33% of old view still rendered, overlapping new view → visible shadowing.

**Fix**: `pushExit.to` = `-root.menuWidth` (fully off-screen left). New view slides in from right over clean background. No overlap.

```qml
pushExit: Transition {
    NumberAnimation { property: "x"; from: 0; to: -root.menuWidth; duration: 260; easing.type: Easing.InOutCubic }
}
```

Corresponding `popEnter` must be updated to match — new view enters from `-menuWidth`, not `-menuWidth/3`:

```qml
popEnter: Transition {
    NumberAnimation { property: "x"; from: -root.menuWidth; to: 0; duration: 260; easing.type: Easing.InOutCubic }
}
```

`popExit` stays `to: root.menuWidth` (new view slides all the way right, fully off-screen) — already correct, no change needed.
