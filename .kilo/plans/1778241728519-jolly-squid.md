# Close Tray Popup When Leaf Menu Item Clicked

## Problem

Clicking a tray menu item (no submenu children) fires `entry.triggered()` but popup stays open. Standard tray behavior: close popup after leaf action.

## Root Cause

`TrayMenuItem.onClicked` → `entry.triggered()` (line 98). No mechanism to close parent popup.

## Solution

Propagate `screenName` from `TrayWidget` → `TrayMenu` → `TrayMenuPage` → `TrayMenuItem`. Emit signal from `TrayMenuItem` on triggered. `TrayMenuPage` catches it and calls `ShellUI.closePopup(screenName)`.

## Changes (4 files)

### 1. `modules/popups/TrayMenuItem.qml`
- Add `signal triggered()`
- After `root.entry.triggered()` on line 98, emit `root.triggered()`

### 2. `modules/popups/TrayMenuPage.qml`
- Add `required property string screenName`
- Add import `../../../services/ui` (ShellUI)
- In `TrayMenuItem` delegate, add `onTriggered: ShellUI.closePopup(page.screenName)`
- Pass `screenName: page.screenName` in submenu page push (line ~112)

### 3. `modules/popups/TrayMenu.qml`
- Add `required property string screenName`
- Pass `screenName: root.screenName` to `menuPage` Component

### 4. `modules/bar/widgets/TrayWidget.qml`
- Pass `screenName: widget.screenName` to `trayMenuComponent` TrayMenu

## Verification

- Restart shell: `quickshell kill && quickshell -p <shell-dir>`
- Open tray menu, click leaf item → popup closes
- Submenu navigation (back button, submenu items) unaffected
